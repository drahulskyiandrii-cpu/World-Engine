## Selection rules

1. Only the documents listed below are implementation-facing canonical artifacts for the covered scope.
2. Every active Word artifact is a complete standalone document. It starts with the corrected audited baseline and preserves relevant earlier content as explicitly historical material.
3. When historical wording conflicts with the corrected audited baseline, the current audited clause has precedence. The historical copy does not reactivate superseded behavior.
4. Exact duplicate blocks are suppressed only when their equality was verified and recorded in the coverage register. Packaging-only headers, footers and empty blocks are excluded from content counts.
5. Superseded active files are preserved under `docs/99_Archive/04_Full_Documentation_Rebuild_2026-09-04/`; the older archive tree remains unchanged.
6. The workbook [coverage and QA register](World_Engine_Full_Documentation_Coverage_and_QA_v1_0.xlsx) records all 166 source files, SHA-256 values, output mappings, content treatment and QA results.
