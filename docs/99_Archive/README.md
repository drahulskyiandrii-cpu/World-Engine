# World Engine documentation archive

This directory preserves superseded documentation exactly as it existed before the 2026-09-04 consolidation.

- Archived files are historical and noncanonical.
- Do not use them to define new implementation behavior.
- Do not edit an archived artifact to create a new current version; create a versioned artifact in the normal active documentation folder instead.
- The active source of truth is listed in [`docs/CANONICAL_DOCUMENTATION_INDEX.md`](../CANONICAL_DOCUMENTATION_INDEX.md).
- Archive paths preserve the original documentation hierarchy so an older file remains easy to locate and recover.

The consolidation did not destroy historical material. It removed superseded files from active working folders, where similar names had made the current version ambiguous.
