# World-Engine
AI-powered simulation framework for creating dynamic, persistent and living game worlds.

Documentation status and implementation-facing artifact selection: [Canonical Documentation Index](docs/CANONICAL_DOCUMENTATION_INDEX.md).

## Active implementation

[MOD-002 Game Adapter](modules/MOD-002_Game_Adapter/README.md) is in development for Skyrim Special Edition and Anniversary Edition on Windows. The current M2.1 baseline provides the portable adapter contracts, lifecycle, capability model, SE/AE profile, optional SKSE/CommonLibSSE NG plugin scaffold and dependency-free tests.

Status: **Prototype**. Skyrim VR is excluded. Compilation and in-game compatibility validation are required before any Supported declaration.
